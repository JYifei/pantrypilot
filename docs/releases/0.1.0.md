# PantryPilot 0.1.0 (pre-release)

Working name. Development milestone **V0.3** (cooking log, meal plan, shopping list) is
included; the app still reports version **0.1.0**. This is a Windows pre-release for review,
not a signed public release. A license has not been chosen yet.

## What you get

- A local-first desktop app: inventory, recipes, shared meal plan / shopping list, cooking
  log, demo nutrition data.
- Fully offline. No account, cloud sync, analytics or telemetry.

## Installer

| Item         | Value                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------- |
| Format       | NSIS (`.exe`), current-user install                                                         |
| Built with   | `pnpm tauri build`                                                                          |
| Code signing | **None.** Windows SmartScreen may warn; that does not mean the file was scanned as malware. |
| Auto-update  | Not included.                                                                               |

After a local build, the installer is written under:

```text
src-tauri/target/release/bundle/nsis/PantryPilot_0.1.0_x64-setup.exe
```

If `CARGO_TARGET_DIR` is set (e.g. by some IDE sandboxes), look under that directory instead
of `src-tauri/target`. A copy used for local smoke tests may also sit in `releases/` (gitignored).

**Checksum:** fill in after the build (SHA-256 of the `.exe` only). Do not distribute a file
whose hash does not match.

```text
SHA-256: 9c45fec1a62745519fb7a24776953cf4cc1057a414fad0c6084ed2231fcf422b
```

GitHub Actions can also produce the same installer via **Actions → Build Windows installer →
Run workflow** (manual). Artifacts expire; download and verify the hash before installing.

## Prerequisites

- Windows 10 or 11, 64-bit.
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (usually already
  present on current Windows).

## Install

1. Close any running PantryPilot window (including `pnpm tauri dev`).
2. Run the setup `.exe`. If SmartScreen appears, use **More info → Run anyway** only if you
   trust the file and its SHA-256 matches.
3. Start **PantryPilot** from the Start menu.

Data lives in one SQLite file (same path as development builds):

```text
%APPDATA%\dev.pantrypilot.desktop\pantrypilot.db
```

Export a backup from **Settings → Export** before upgrading or uninstalling if you care about
the data.

## Smoke checks (this machine or a clean PC / Windows Sandbox)

1. Install while offline (or after install: disconnect and launch).
2. Quit and reopen: inventory / plan still there.
3. **Settings → Export**, then import that backup on a fresh profile if you can.
4. If you already had a database from an older build, launching the installed app should apply
   migrations (up to migration 5) without wiping data. Copy `pantrypilot.db*` first if you want
   a byte-for-byte restore.
5. Uninstall from **Settings → Apps**. Confirm whether
   `%APPDATA%\dev.pantrypilot.desktop\` remains (user data is often left behind on purpose).

## Known limitations

- Unsigned installer; Windows may show SmartScreen.
- Tested packaging target: **Windows only**. macOS / Linux installers are not claimed.
- Nutrition values are **demo data**, not an official food composition table.
- Cooking records have no nutrition snapshot and cannot be undone.
- Shopping list: optional ingredients omitted; gaps are edible grams; manual items cannot be
  entered as stock directly.
- No auto-update.

## Build from source

```bash
pnpm install
pnpm tauri build
```

Needs Node 22+, pnpm 12, Rust, and the
[Tauri 2 prerequisites](https://tauri.app/start/prerequisites/) (on Windows: VS Build Tools with
the C++ workload, WebView2).
